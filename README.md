# cpez-led-c

A lightweight project for turning on an LED without installing any software or complex toolchain. Built around a fast C + Wokwi workflow designed to get you from idea to running simulation in under 30 seconds.

## Overview

This repository demonstrates a minimal embedded-style workflow for controlling an LED using C and the Wokwi simulator. The project is intended to be easy to understand, quick to run, and suitable for learning, teaching, and rapid prototyping.

The original Spanish description of the project was: "prende un LED sin instalar nada. C + Wokwi en 30s. Escanea, compila, prende."

## Features

- Minimal LED example written in C
- Fast simulation workflow using Wokwi
- No local installation required for the browser-based demo experience
- Ideal for beginners learning GPIO and embedded concepts
- Clean, easy-to-follow code structure

## Getting Started

### Option 1: Open the project directly

1. Clone or download this repository.
2. Open `index.html` in your browser.
3. Interact with the demo as needed.

### Option 2: Run the example in Wokwi

1. Open Wokwi in your browser.
2. Create a new Arduino-compatible project.
3. Copy the C source from this project into the Wokwi editor.
4. Compile and run the simulation.
5. Verify that the LED is turned on.

## Requirements

- A modern web browser
- Optional: Wokwi account or access to the Wokwi online simulator

## Usage

This project is intentionally small and didactic. It is meant to demonstrate how a basic digital output can be configured and used to drive an LED. It is a good starting point for learning:

- GPIO pin configuration
- Digital output control
- Embedded programming fundamentals
- Simulation-based development workflows
